# Sitio estatico de Aisa Inmobiliaria

Este directorio contiene las paginas HTML y sus recursos usados por `DAPT/index.html`.

El proyecto de Vercel usa este directorio como raiz, ejecuta `node build.mjs` y publica el contenido generado en `dist/`.

Vercel publica las paginas HTML con rutas limpias (por ejemplo, `/compra`) mediante `vercel.json`; los enlaces internos usan esas rutas y `/` como inicio.
